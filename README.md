This repository comprises of two interconnected components and can be integrated either by the **_WinCC OA Extensions_** addon as provided on GitHub or manually by cloning it locally.

* The WinCC OA addon for hosting a language server (LSP) to provide data model information about Datapoints and CNS / Plantmodel definition.
* The [VS Code Extension](winccoa-vscode-extension/README.md) to connect to the language server and enhance user coding and debugging by providing code-completion and mouse-hover information.
